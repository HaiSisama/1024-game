# 1024 小游戏实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 实现一个单文件 1024 数字合并小游戏（4x4/5x5 可切换、方向键/滑动操作、目标拼出 1024、胜利后可继续）。

**Architecture:** 单文件 `index.html` 内分三层：核心逻辑层（纯函数，`/* CORE-START */` 与 `/* CORE-END */` 标记包裹，零 DOM 依赖，由 Node 测试驱动）+ 输入层（键盘/触摸/按钮）+ 渲染层（CSS Grid 背景格 + 绝对定位方块 + transform 动画）。核心逻辑以 TDD 开发；视图层以手动验收验证。

**Tech Stack:** 原生 HTML + CSS + JavaScript，零依赖；Node（仅用于跑测试）；Google Fonts Quicksand（可回落系统字体）。

**Spec:** `docs/superpowers/specs/2026-08-17-1024-game-design.md`（本计划的所有行为均以 spec 为准，实现前请通读）

## Global Constraints

- 交付物为单文件 `index.html`，禁止引入任何 JS 库/框架；开发测试为 `tests/core.test.js`（Node 运行）
- 核心逻辑必须是纯函数、零 DOM 引用；必须以 `/* CORE-START */` 与 `/* CORE-END */` 标记包裹（测试通过正则提取）
- 新方块生成：2（90%）/ 4（10%）
- 合并得分 = 合并出的新数字；最高分按尺寸分开存 localStorage，key 为 `best-4` / `best-5`，读取需 try/catch
- 界面文案（中文）：分数 / 最高分 / 新游戏 / 继续游戏 / 再来一局 / 重新开始；胜利标题「🎉 1024！」；失败标题「没有可移动的方块了」
- 方块颜色公式：`色相 = 155 − 12 × log₂(v)`、`饱和度 42%`、`明度 = 88% − 1.5% × log₂(v)`；特例：1024 → `#FFD97A`，≥2048 → `#F5C558`，0 → `transparent`
- 基础色板：页面底 `#F6F8F7`、棋盘卡 `#FFFFFF`、空背景格 `#EEF2F0`、文字墨青 `#2F3B36`、次要文字 `#6B7A74`、强调薄荷绿 `#4FAE8E`、棋盘圆角 16px、方块圆角 10px
- 滑动过渡 120ms；滑动阈值 30px；一次触摸序列只触发一次移动
- 键盘：方向键 + WASD（大小写），`preventDefault()` 阻止页面滚动；`touch-action: none` + `user-select: none`
- 状态机：`playing → won弹层 →（继续游戏|重新开始）→ playing（继续时 won=true 不再触发）`；`playing → over弹层 →（再来一局）→ playing`；弹层打开期间（paused）输入暂停
- 胜利判定只触发一次（`won` 标志）；死局 = 无空格且无相邻相等
- 尊重 `prefers-reduced-motion`（动画跳变）；按钮有 `:focus-visible` 焦点框；弹层 `aria-live="polite"`
- 本目录当前不是 git 仓库——Task 1 中 `git init` 并做首次提交
- 所有核心函数签名以本计划 Interfaces 块为准，后续任务不得改名

```js
function slideLine(line) {
  const tiles = line.filter(v => v !== 0);
  const out = [];
  let gained = 0;
  for (let i = 0; i < tiles.length; i++) {
    if (i + 1 < tiles.length && tiles[i] === tiles[i + 1]) {
      const merged = tiles[i] * 2;
      out.push(merged);
      gained += merged;
      i++; // 跳过被合并的伙伴
    } else {
      out.push(tiles[i]);
    }
  }
  while (out.length < line.length) out.push(0);
  return { line: out, gained };
}
```

```js
function cellAt(i, j, dir, size) {
  switch (dir) {
    case 'left':  return [i, j];
    case 'right': return [i, size - 1 - j];
    case 'up':    return [j, i];
    case 'down':  return [size - 1 - j, i];
  }
}

function move(board, dir) {
  const size = board.length;
  const next = Array.from({ length: size }, () => Array(size).fill(0));
  let moved = false;
  let gained = 0;
  for (let i = 0; i < size; i++) {
    const line = [];
    for (let j = 0; j < size; j++) {
      const [r, c] = cellAt(i, j, dir, size);
      line.push(board[r][c]);
    }
    const res = slideLine(line);
    gained += res.gained;
    for (let j = 0; j < size; j++) {
      if (res.line[j] !== line[j]) moved = true;
      const [r, c] = cellAt(i, j, dir, size);
      next[r][c] = res.line[j];
    }
  }
  return { board: next, moved, gained };
}
```

```js
function planMove(board, dir) {
  const size = board.length;
  const plan = [];
  for (let i = 0; i < size; i++) {
    const sources = [];
    for (let j = 0; j < size; j++) {
      const [r, c] = cellAt(i, j, dir, size);
      if (board[r][c] !== 0) sources.push({ r, c, value: board[r][c] });
    }
    const { line } = slideLine(sources.map(s => s.value));
    let p = 0;
    for (let k = 0; k < line.length; k++) {
      const v = line[k];
      if (v === 0) break;
      const [r, c] = cellAt(i, k, dir, size);
      if (sources[p].value === v) {
        plan.push({ from: { r: sources[p].r, c: sources[p].c }, to: { r, c }, merged: false });
        p++;
      } else {
        // 合并：靠近移动方向的方块存活
        plan.push({ from: { r: sources[p].r, c: sources[p].c }, to: { r, c }, merged: false });
        plan.push({ from: { r: sources[p + 1].r, c: sources[p + 1].c }, to: { r, c }, merged: true });
        p += 2;
      }
    }
  }
  return plan;
}
```

```js
function spawnTile(board, rng = Math.random) {
  const size = board.length;
  const empty = [];
  for (let r = 0; r < size; r++) {
    for (let c = 0; c < size; c++) {
      if (board[r][c] === 0) empty.push({ r, c });
    }
  }
  if (empty.length === 0) return { board, tile: null };
  const pos = empty[Math.floor(rng() * empty.length) % empty.length];
  const value = rng() < 0.9 ? 2 : 4;
  const next = board.map(row => row.slice());
  next[pos.r][pos.c] = value;
  return { board: next, tile: { row: pos.r, col: pos.c, value } };
}

function applyMove(state, dir, rng = Math.random) {
  const { board: slid, moved, gained } = move(state.board, dir);
  if (!moved) {
    return { board: state.board, score: state.score, moved: false, gained: 0, tile: null };
  }
  const { board, tile } = spawnTile(slid, rng);
  return { board, score: state.score + gained, moved: true, gained, tile };
}
```

```js
function canMove(board) {
  const size = board.length;
  for (let r = 0; r < size; r++) {
    for (let c = 0; c < size; c++) {
      const v = board[r][c];
      if (v === 0) return true;
      if (c + 1 < size && board[r][c + 1] === v) return true;
      if (r + 1 < size && board[r + 1][c] === v) return true;
    }
  }
  return false;
}

function isWin(board) {
  return board.some(row => row.includes(1024));
}

function isOver(board) {
  return !canMove(board);
}
```

```js
function tileColor(v) {
  if (v === 0) return 'transparent';
  if (v === 1024) return '#FFD97A';
  if (v >= 2048) return '#F5C558';
  const exp = Math.log2(v);
  const hue = 155 - 12 * exp;
  const light = 88 - 1.5 * exp;
  return `hsl(${hue}, 42%, ${light}%)`;
}
```

```js
    const list = byDest.get(key) || [];
    list.push(m);
    byDest.set(key, list);
  }
  for (const list of byDest.values()) {
    if (list.length === 2) {
      const keeper = list.find(m => !m.merged);
      const loser = list.find(m => m.merged);
      keeper.mergeValue = keeper.t.value * 2;
      this.tiles.delete(loser.t.id);
      loser.removeEl = true;
    }
  }
  for (const m of plan) {
    if (!m.t) continue;
    m.t.row = m.to.r;
    m.t.col = m.to.c;
    this.positionTile(m.t);
  }

  // 阶段二：过渡结束后落地
  window.setTimeout(() => {
    if (this.state !== st) return; // 期间已重开新局
    for (const m of plan) {
      if (m.removeEl) m.t.el.remove();
      if (m.mergeValue) {
        m.t.value = m.mergeValue;
        m.t.el.textContent = m.mergeValue;
        m.t.el.style.backgroundColor = tileColor(m.mergeValue);
        m.t.el.style.fontSize = (this.geometry().cell * fontSizeFor(m.mergeValue)) + 'px';
        m.t.el.classList.add('tile-merge');
        if (m.mergeValue >= 1024) m.t.el.classList.add('gold');
        window.setTimeout(() => m.t.el.classList.remove('tile-merge'), 160);
      }
    }
    if (res.tile) this.addTile(res.tile.row, res.tile.col, res.tile.value, true);
    this.updateHud();
    if (isWin(this.state.board) && !this.state.won) {
      this.state.won = true;
      this.showOverlay('win');
    } else if (isOver(this.state.board)) {
      this.state.over = true;
      this.showOverlay('over');
    }
  }, this.REDUCED ? 0 : 120);
},

showOverlay(kind) {
  this.paused = true;
  this.overlayKind = kind;
  if (kind === 'win') {
    overlayTitleEl.textContent = '🎉 1024！';
    overlayTextEl.textContent = '拼出 1024！可以继续合成更高数字，也可以重新开始。';
    overlayPrimaryEl.textContent = '继续游戏';
    overlaySecondaryEl.textContent = '重新开始';
    overlaySecondaryEl.classList.remove('hidden');
  } else {
    overlayTitleEl.textContent = '没有可移动的方块了';
    overlayTextEl.textContent = '本局得分 ' + this.state.score + ' 分';
    overlayPrimaryEl.textContent = '再来一局';
    overlaySecondaryEl.classList.add('hidden');
  }
  overlayEl.classList.remove('hidden');
},

hideOverlay() {
  overlayEl.classList.add('hidden');
},
```
